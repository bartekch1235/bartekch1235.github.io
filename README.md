Bounty Hunter webpage
Polityka Prywatności – Bounty Hunters

Data wejścia w życie: 10 czerwca 2026 r.

1. Informacje ogólne

Niniejsza Polityka Prywatności opisuje zasady dotyczące aplikacji mobilnej Bounty Hunters („Aplikacja”).

2. Gromadzenie danych

Aplikacja nie gromadzi, nie przechowuje ani nie przetwarza danych osobowych użytkowników.

Aplikacja nie wymaga:

tworzenia konta,
logowania,
podawania danych osobowych,
udostępniania lokalizacji.
3. Dane techniczne

Aplikacja nie zbiera danych analitycznych ani diagnostycznych służących identyfikacji użytkownika.

4. Usługi podmiotów trzecich

Obecna wersja Aplikacji nie korzysta z usług podmiotów trzecich służących do:

reklam,
analityki,
płatności,
śledzenia aktywności użytkownika.
5. Dzieci

Aplikacja może być używana przez osoby w każdym wieku. Ponieważ nie są gromadzone żadne dane osobowe, Aplikacja nie przetwarza danych dzieci.

6. Bezpieczeństwo

Ponieważ Aplikacja nie przechowuje danych użytkowników, ryzyko związane z przetwarzaniem danych osobowych jest ograniczone do minimum.

7. Zmiany w Polityce Prywatności

Polityka Prywatności może być aktualizowana w przypadku zmian funkcjonalności Aplikacji. Nowa wersja będzie publikowana wraz z aktualizacją Aplikacji.
